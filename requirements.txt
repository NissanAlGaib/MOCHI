# Phase 8 - Stage II semantic detection. REQUIRED, not optional.
#
# These were commented out for a long time, on the reasoning that Stage II is
# flag-gated and torch is ~2.5 GB, so an evaluator should not pay for a stack
# they might not load. That reasoning was wrong in one important way: Stage I
# alone measured 5.9% recall. An install without Stage II is not a lighter
# MOCHI, it is one that misses almost every attack - and the flag defaults on
# now, so it fails loudly rather than degrading in silence.
#
# Prefer the CPU wheel, as the Dockerfile does: Stage II runs on CPU, and
# 4.3 GB of the 4.4 GB CUDA build is kernels that would never load.
#
#   pip install --index-url https://download.pytorch.org/whl/cpu torch
#
torch>=2.4.0
transformers>=4.45.0
# sentence-transformers is NOT used: its default mean pooling is the behaviour
# Stage II specifically avoids (see training/model.py). The encoder is loaded
# through transformers directly so the pooling layer is ours.

# Tagalog content filter (mochi/preprocess/code_switch.py).
#
# Deliberately NOT installed by default, same reasoning as Stage II above: off
# unless MOCHI_ENABLE_TAGALOG_TRANSLATION=true, and argostranslate declares
# stanza as a hard dependency, which pulls in torch (~2.5 GB) regardless of
# whether Stage II is also enabled. Every code path in code_switch.py is
# tested through a stubbed translator. Install when enabling this filter:
#
#   pip install argostranslate wordfreq
#
# argostranslate>=1.11.0    # tl<->en translation - the only maintained library with this pair
# wordfreq>=3.1.0           # no torch; resolves words the curated lexicon in
#                           # normalize.py cannot place on its own (see the
#                           # code_switch.py module docstring for the false-
#                           # strip bug this specifically fixes)
#
# After installing argostranslate, download the tl<->en package once:
#   python -c "import argostranslate.package as p; p.update_package_index(); \
#       pkg = next(x for x in p.get_available_packages() if x.from_code=='tl' and x.to_code=='en'); \
#       p.install_from_path(pkg.download())"
