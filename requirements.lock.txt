# Exact versions the thesis results were produced with.

# requirements.txt states what MOCHI needs; this states what it actually ran
# on. The two serve different purposes and both are kept:
#
#   requirements.txt       lower bounds, so an install picks current wheels
#   requirements.lock.txt  this file, so a result can be reproduced
#
# Written because "torch>=2.4.0" does not identify a build, and the numbers in
# Chapter IV came from one. Stage II's scores depend on the transformers
# version that loads the encoder, and the image and audio arms depend on the
# OCR and speech runtimes - rapidocr 1.4.4 produced the 180-degree rotation
# finding on banking77-2287, and a different build may not.
#
# Reproduce with:
#   python -m venv .venv
#   .venv/Scripts/pip install -r requirements.lock.txt
#
# Regenerate after changing dependencies:
#   .venv/Scripts/pip freeze --all > requirements.lock.txt
#   (then restore this header)
#
# Captured on Python 3.11, Windows 11. The torch wheel here is the CUDA build
# that happened to be installed; the Dockerfile installs the CPU wheel
# deliberately, and Stage II runs on CPU in every measurement either way -
# MOCHI_STAGE2_DEVICE defaults to cpu.
#
